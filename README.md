# Santiago | Data Science, Machine Learning & Security-Aware Architect

Perfil técnico enfocado en el diseño, entrenamiento y despliegue de modelos de Machine Learning y Deep Learning, junto con la orquestación de infraestructuras SaaS seguras y escalables. Arquitecto principal de un proyecto de software enfocado en integrar soluciones de inteligencia artificial con arquitecturas multi-tenant, priorizando el rendimiento, la modularidad y la seguridad de los datos.

### ◾ Áreas de Enfoque y Desarrollo Actual

*   **Machine Learning & Deep Learning:** Desarrollo de pipelines de datos y entrenamiento de modelos. Implementación de redes neuronales y orquestación de LLMs locales (Danswer/Onyx, CrewAI) para automatización cognitiva.
*   **Arquitectura SaaS & Proyectos Multi-tenant:** Construcción de sistemas robustos y plantillas escalables para E-commerce y control de stock, utilizando **Django** como framework principal e integrando bases de datos relacionales con APIs de alto rendimiento.
*   **Seguridad e Infraestructura:** Securización de servidores VPS, manejo de permisos estrictos y aislamiento de procesos mediante **Docker** y proxies inversos como **Nginx**. Enfoque preventivo en la integridad de las aplicaciones web y la protección de endpoints.
*   **I+D Avanzado:** Investigación activa e implementación de conceptos de Computación Cuántica y arquitecturas descentralizadas (Blockchain) para futuros modelos de cifrado y procesamiento.

### ◾ Entorno Operativo y Flujo de Trabajo (Tactical Stack)

El flujo de desarrollo está diseñado para maximizar la velocidad y minimizar la latencia de interacción, operando exclusivamente bajo arquitecturas Linux y metodologías *terminal-first*.

*   **Sistemas y Control de Ventanas:** Operaciones centralizadas en Linux Mint, gestionado a través del gestor de ventanas en mosaico i3wm para un control táctico del espacio de trabajo.
*   **IDEs y Edición:** Uso de **Antigravity IDE** como entorno principal para desarrollo avanzado, complementado con Helix y Micro para ediciones rápidas y precisas directamente desde la terminal.
*   **Operaciones Móviles y Remotas:** Despliegue, monitorización y administración de servidores en movimiento utilizando **Termux** para acceso SSH seguro y scripting en entornos móviles.
*   **Automatización e IA Asistida:** Integración de **Gemini CLI** y **OpenCode** directamente en la terminal para revisión de código en tiempo real, refactorización algorítmica y auditoría de seguridad automatizada.
